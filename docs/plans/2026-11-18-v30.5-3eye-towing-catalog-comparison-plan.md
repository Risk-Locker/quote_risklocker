## Mandatory 10-Point Edge-Case Matrix
1. **Null / Missing PDF Fields:** Missing `vehicle_class` or `product_name` falls back safely to Eye 2 cached/search make-model grounding; never classifies passenger SUVs as Lorry or EV.
2. **Decimal / Unit Precision:** Monetary (`RM 300`, `RM 400`, `RM 500`, `RM 600`) and distance (`50 km`, `100 km`, `200 km`, `300 km`, `365 km`) vs `Unlimited` stay exact without `RM 200` coercion or float drift.
3. **Coverage Type Isolation:** `Third Party` and `TPFT` catalogs exclude complimentary Comprehensive towing unless explicitly included; Commercial Lorry excludes private towing perks.
4. **Tiered Plan Specificity:** `Motor PA Plus` (`Plan 1`..`Plan 4`), `E-Assist Smart Driver` (`Plan 1` vs `Plan 2 / EV Plan`) resolve exact plan condition over wildcards.
5. **User Manual Overrides Preserved:** Workspace Box 1 edits (`manual_override` / `description_override` / `typed_value_override`) and Comparison `manual_overrides` remain editable and survive rescans & PDF renders.
6. **Design 2 Live Canvas <-> A4 PDF 1:1 Parity:** Identical Box 1 cards, limit pills/titles, descriptions, and 24-card grid bounds across React preview and Playwright Chromium PDF.
7. **Gemini Quota & Timeout Resilience:** Level-2 online search hits `vehicle_models` DB cache first, calls `google_search` only on cache miss/ambiguity under `PacerSentinel`, and degrades gracefully with explicit warning if rate-limited.
8. **Concurrent Queue & Re-Upload Race Safety:** Batch upload (`CHUNK_SIZE=3`) preserves `tenureId` before `"completed"` renders and atomically syncs `TenureComparisonEntry` upon `replace`.
9. **Legacy Catalog & Dirty Test Row Hygiene:** Migration `080` removes HTTP test strings, publishes drafted active catalogs (`QBE Private Car Protector`), and remains backward-compatible with older sessions.
10. **HTTP Verb & Security Purity:** `GET /comparison/{id}` stays read-only; mutations stay gated behind `require_role` + CSRF on `POST`/`PATCH`/`DELETE`.
