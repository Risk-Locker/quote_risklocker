# Security & Compliance Audit: AppSec, RBAC, Middleware, CSRF, `eval()` DoS & PDPA PII

> **Textbook Purpose**: Security in a financial & insurance SaaS platform (handling Malaysian NRICs, vehicle plates, bank details, and legally binding contracts) is NOT optional. Under Malaysia's **Personal Data Protection Act (PDPA 2010)**, leaking customer NRICs or letting unauthorized users mutate financial settings carries direct legal liability. Every flaw below was verified directly in the current codebase.

## 2. Deep Technical Remedies for Every Vulnerability

### 2.1 Fixing RBAC & Validation Gaps (`S-01`, `S-06`)
1. Immediately enforce `require_role(user, Role.SUPER_ADMIN, Role.ADMIN)` on `POST /admin/settings/runner-fee` AND introduce a strict Pydantic schema:
   ```python
   class RunnerFeeUpdateRequest(BaseModel):
       amount: Decimal = Field(ge=Decimal("0.00"), le=Decimal("500.00"))
   ```
2. Add an automated **CI Route Security Scanner Test** that inspects every registered FastAPI route under `/admin/*`, `/settings/*`, `/builder/*`, `/extraction/*`, and asserts that **every non-read-only route explicitly declares an authorization dependency or `require_role()` check** — impossible to regress silently again!
3. Separate `Role.DEV` permissions: `DEV` may access `/settings/system-checks` and AI/worker diagnostics in staging, **never** financial defaults, pricing schedules, or customer PII in production unless explicitly scoped.

### 2.2 Safe AST Expression Evaluator Replacing `eval()` (`S-02`)
- Delete Python `eval()` in [`road_tax_engine.py:26`](file:///c:/Users/mahmud/Desktop/Code/risklocker/quote_risklocker/backend/app/services/road_tax_engine.py#L26).
- Implement a 40-line `ast.parse(..., mode="eval")` walker allowing **strictly** `+`, `-`, `*`, `/` (explicitly banning `**` `Pow`), constants (`<= 1_000_000`), identifier `cc`, and safe functions `ceil`, `floor`, `min`, `max` using `Decimal` arithmetic (`ZeroDivisionError` caught cleanly -> `RoadTaxFormulaError`).
- Also audit [`formula_evaluator.py`](file:///c:/Users/mahmud/Desktop/Code/risklocker/quote_risklocker/backend/app/services/formula_evaluator.py) in Phase 1 to confirm no second `eval()` exists for benefit cost formulas!

### 2.3 Hardened Edge Auth, Fail-Closed Origin Checks & Shared Lockout (`S-03`, `S-04`, `S-05`)
1. **Middleware Default-Deny**: Rewrite [`middleware.ts`](file:///c:/Users/mahmud/Desktop/Code/risklocker/quote_risklocker/frontend/src/middleware.ts) `matcher` to exclude only public assets (`/_next`, `/favicon.ico`, `/assets/brand/`) and `/login` — every other route (including `/comparison`, `/ledger`, `/ai-context`) requires valid session authentication. Perform lightweight HMAC cookie format/signature check at Edge OR verify via internal `/api/auth/me` before rendering restricted Admin/Builder layouts.
2. **HTTP Security Middleware**: Remove `print("DEBUG: ...")` at `http_security.py:40`; log structured JSON warning (`logger.warning`). Reject missing `Origin`/`Referer` on all state-mutating requests (`POST/PUT/PATCH/DELETE`) consistently in staging and production (exempting only explicit API health probes or signed webhooks).
3. **Database / Redis-Backed Login Lockout**: Move `_login_failures` / `_lockout_until` (`auth_service.py:34-37`) into PostgreSQL (`auth_login_attempts` table with indexed `email_hash` + `window_start`, or Redis) so brute-force protection holds across multiple Uvicorn workers and deployments.

### 2.4 Ephemeral Storage Security & PDPA Data Hygiene (`S-07` + Storage)
1. **No PII in Code/Git**: Purge all customer names, plate numbers, quotation references, and live bank account numbers from Python/TSX templates (`template_renderer.py`, `template_renderer_design2.py`, `design2-canvas.tsx`, `builder/page.tsx`). Move bank/QR metadata into DB `agency_profiles` and use obviously synthetic placeholders (`SAMPLE USER`, `ABC 1234`, `00000000000`) exclusively inside Builder sample previews.
2. **HTML/XSS Escape Discipline in Chromium PDF Rendering**: Ensure every interpolated draft field rendered inside `template_renderer*.py` passes strictly through `html.escape(..., quote=True)` — including URLs, asset labels, SVG `<title>` tooltips, and add-on descriptions — and block network access inside Playwright Chromium (`page.route("**/*", ...)` aborting external URLs except data/local assets) so no malicious PDF extraction payload can ever trigger **SSRF inside headless Chromium**!
3. **Audit Logging**: Log every PII export (CSV export, WhatsApp teaser generation, PDF download, Record view/edit) with `actor_id`, `ip_address`, `entity_id`, and timestamp into immutable `audit_events`.
