## 3. Database Schema & API Integration Specification
> Architecture Blueprint: To ensure immediate system ingestion and database-ready parsing, the benefit catalog is mapped into standard relational SQL and JSON entities below:

`sql
-- Database Table Schema: motor_benefit_catalog
CREATE TABLE motor_benefit_catalog (
 benefit_id VARCHAR(64) PRIMARY KEY,
 vehicle_type ENUM('PRIVATE_CAR', 'COMMERCIAL_CAR', 'PRIVATE_MOTORCYCLE', 'COMMERCIAL_MOTORCYCLE', 'COMMERCIAL_LORRY_OWN_GOODS', 'COMMERCIAL_LORRY_HAULAGE') NOT NULL,
