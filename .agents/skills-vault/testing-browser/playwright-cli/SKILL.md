# Playwright CLI Tools

Commands and usage for Playwright CLI.

## Common Commands

- Run Playwright test suite: `npx playwright test`
- Run headed test with inspector: `npx playwright test --headed --debug`
- View trace file: `npx playwright show-trace trace.zip`
- Codegen: `npx playwright codegen http://localhost:3000`
