# 21st.dev Opt-In UI Plugin (`ui-21st-dev`)

Optional repo-local plugin template connecting to `https://21st.dev/api/mcp`.

- Ships **`"disabled": true`** by default so zero broken auth prompts or extra key requirements occur unless you want it.
- To enable: create a key at `https://21st.dev/mcp`, open `[ui-21st-dev](customization://ui-21st-dev)` in Antigravity Customizations, enter `TWENTYFIRST_API_KEY`, and enable the plugin.
- Never commit API keys to `mcp_config.json` or `.git`.
