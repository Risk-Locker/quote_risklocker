# References & Asset Policies

## 1. Asset Management Policy

- **Image & Static Assets**: Place production static assets in `public/` or `assets/`.
- **Private Data & Secrets**: Never store customer PDFs, production database dumps, or private API keys inside this repository.
- **External Dependencies**: Document all third-party CDNs, SDKs, or external services utilized by this project.

## 2. External Technical References

- **Framework Documentation**: Link to relevant official docs (e.g. Next.js, FastAPI, PostgreSQL).
- **Standards & Specifications**: Link to RFCs, design files (Figma), or industry protocols.
